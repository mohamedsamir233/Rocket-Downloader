# 🚀 Rocket Downloader

Rocket Downloader is a desktop application built with **Python** and **PyQt5** that enables users to download YouTube videos or extract audio through a simple and user-friendly graphical interface.

## ✨ Features

- Download YouTube videos.
- Download audio (MP3).
- Select video quality before downloading.
- Choose a custom download location.
- Display video title and file size.
- Real-time download progress.
- Simple and responsive desktop interface.

## 🛠️ Technologies Used

- Python
- PyQt5
- pytube
- Requests

## 🚀 Installation

```bash
git clone https://github.com/mohamedsamir233/Rocket-Downloader.git
cd Rocket-Downloader
pip install -r requirements.txt
python main.py
```
